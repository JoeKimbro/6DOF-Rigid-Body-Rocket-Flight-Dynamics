The user is building a 6DOF rigid body rocket flight simulator incrementally (1DOF → 6DOF) as a learning project. They are learning flight dynamics from scratch and building understanding from first principles.

- Language: C++
- Current branch: 3DOF (as of 2026-06-03)
- Learning style: incremental, hands-on — they write code themselves; mentor role is Socratic teaching only
- They understand basic Newtonian mechanics well enough to implement 2DOF with gravity, drag, and thrust decomposition
- They have begun reaching into rotational dynamics (pitching moment, AoA, angular acceleration) on their own — shows initiative and some intuition about the rotation chain
- They leave self-notes in code comments (e.g., the table at bottom of Integrator3DOF.cpp tracking what they planned vs. what exists) — this is a useful signal for gauging their own awareness of gaps
